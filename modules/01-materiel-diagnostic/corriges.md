# Corrigés expliqués

## Exercice 1 Quatre points

CPU → C ; RAM → D ; SSD → A ; GPU → B. Le stockage garde les fichiers après l’arrêt. La RAM aide les programmes en cours à travailler, mais ne remplace pas un SSD.

## Exercice 2 Quatre points

Symptôme : lenteur lors de l’ouverture de nombreux programmes, signalée depuis hier. Hypothèse : processeur insuffisant ou défaillant. Questions possibles : quels programmes et combien ? Un changement ou une mise à jour a-t-il eu lieu ? Le problème existe-t-il au démarrage ou seulement après un certain temps ? Un point pour le symptôme, un pour l’hypothèse, un par question pertinente.

## Exercice 3 Quatre points

Exemple : vérifier la source de l’écran ; contrôler les deux extrémités du câble ; essayer un câble connu fonctionnel du même type. Une source corrigée peut suffire à rétablir l’image ; un changement de câble concluant oriente vers le câble ou son branchement. Un résultat négatif ne prouve pas une panne GPU. Trois points pour des vérifications expliquées, un pour l’absence de conclusion prématurée.

## Exercice 4 Cinq points

Demande : écran noir après déplacement du bureau. Constat : écran alimenté, source HDMI sélectionnée et câble DisplayPort. Action : sélectionner DisplayPort. Vérification : image rétablie sur le bureau Windows ; demander à Léa de vérifier son usage habituel. Statut : affichage rétabli, clôture après confirmation utilisateur. Un point par rubrique. Ne pas inventer un test prolongé qui n’a pas eu lieu.

## Exercice 5 Trois points

La RAM est l’espace de travail temporaire ; le SSD conserve les fichiers. Les capacités indiquent deux usages différents. La fiche aide à identifier la machine, mais ne suffit pas à garantir une compatibilité RAM : il faut la référence exacte et les caractéristiques prises en charge par la carte mère. Un point par idée.
